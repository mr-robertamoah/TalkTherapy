# "I need help now" -- quick help chat, part 1: the core (SCRUM-33, TT-4.4a)

The first of three PRs (TT-4.4a core; TT-4.4b admin queue and escalation; TT-4.4c follow-up and
retention). Planned with the user on 2026-11-07/08 -- see `documentation/decision-log.md`.

## What was built

### "I need help now", on every page
- A red **I need help now** button sits at the bottom left of every page -- signed in or not, the
  admin area, the Suspended page, chats. It opens a dialog that always starts with **"If you or
  someone else is in immediate danger -- call now"** and the emergency number(s) for the person's
  country (their profile country; Ghana when unknown), each a tap-to-call link with the date it was
  checked. **"Change country"** opens a searchable country picker. A country without a verified
  number says "Contact your local emergency services in {country} now" -- never another country's
  number, never a guess. The dialog says TalkTherapy isn't an emergency service.
- Signed out: "Sign in to chat with a counsellor who is available right now."

### Asking for a counsellor (signed in)
- "What's happening? (optional)" -- one line -- and "Don't show my name to the counsellor"
  (starts from the person's saved anonymity preference), then **Ask for a counsellor now**.
- While waiting: "Looking for a counsellor…" with a timer and **Stop waiting**. When someone answers,
  the person is taken to the chat. Nobody answering within 10 minutes: "No counsellor could answer
  in time…" with the number and **Ask again**.
- One live request per person (asking again returns the same one). A limit of 3 a hour (1 for a
  suspended account).
- **Everyone signed in can ask** (the user's decision): a minor whose therapies are paused (no
  guardian) can text; a **suspended account** can too -- with a stricter limit, and the counsellor is
  never told.

### Counsellors on call
- **My Dashboard → Urgent help → Be available now** (verified, unsuspended counsellors only). It lasts
  4 hours, then switches off on its own ("Extend 4 hours", "Stop being available"). Help chats are
  free and unpaid.
- When someone asks, every available counsellor (not the person themselves, not anyone already in a
  help chat) gets **"Someone needs help now"**: first name or "Anonymous", adult or under 18, country,
  languages, the person's note. Nothing else -- not whether the account is suspended.
- **Accept**: the first counsellor to accept is connected; anyone else sees "Someone else answered."

### The chat
- `/help/chat/{id}`: a private chat between the two -- text, and for an adult an **audio call**
  (audio only; a minor needs a guardian's consent, the existing rule). Either side can **End chat**.
  Afterwards both can still read it, read-only.
- A chat ends on its own after 60 minutes.
- Behind it: a free, private therapy with one in-progress session (so the existing audio-call
  machinery is reused), kept out of every therapy list, count, calendar, dashboard and stat.

### Emergency numbers (admin)
- **Administration → Safety → Emergency numbers**: every admin can see them; only a super admin can
  add, edit or remove one. Each needs the country, label, number, notes (optional), the official
  source link, who verified it and when (not in the future). Every change is kept (append-only).
  A number checked over 6 months ago is flagged "Review due" (still shown).

### Country picker (the user's request)
- One searchable country list (ISO 3166, generated by `npm run countries:generate` from
  `i18n-iso-countries`), shared by the server and the UI. It replaced the old external countries API
  in the profile, admin user and licensing-authority forms. Other spellings match ("Ivory Coast").

## How to try it

`docker compose up -d`, then http://localhost:8000. Password for every account: `password`.

1. **Signed out:** open any page, tap **I need help now**: the (fake, seeded) Ghana number, "Change
   country" (try Kenya: "contact your local emergency services"), and a sign-in prompt.
2. **Two browsers:** in one, log in as `help_demo_counsellor` and open **My Dashboard** (check "Urgent
   help" says Available; if not, **Be available now**). In another (private window), log in as
   `help_demo_user`, tap **I need help now**, write a note, tick "Don't show my name", **Ask for a
   counsellor now**. The counsellor gets "Someone needs help now" (Anonymous, the note) -- **Accept**.
   Both are in the chat; send messages both ways; **End chat** -- it stays readable for both.
3. **First to accept:** also log in as `help_demo_counsellor_two` in a third window; ask again; accept
   in one -- the other sees "Someone else answered".
4. **Minor:** as `help_demo_minor`, the chat says audio needs a parent or guardian's consent.
5. **Admin:** as `suspension_demo_admin` (super), **Administration → Emergency numbers**: add, edit,
   remove. As `suspension_demo_normal_admin`: view only.

## Not in this PR

- The admin live queue, alerts after 60 s / 3 min, ringing again or one counsellor (TT-4.4b).
- Inviting the person into a regular therapy afterwards; 1-year retention and the /privacy text
  (TT-4.4c).
- Web push: a counsellor is only rung while the app is open (follow-up).
