# Sprint Plan

This plan organizes the backlog into logical 2-week sprints, prioritizing stability and unifying the codebase first, followed by the high-priority discussion features, and then the new Organization capabilities.

## Sprint 1: Stability & Unification Foundation
**Goal**: Resolve critical bugs, technical debt (Unification), and UI polish to ensure a solid base for new features.
*   **Story 3.1 (Unification Completion)**: Ensure `UnifiedTherapy.vue` is bulletproof.
*   **Story 7.3 (502 Error Fix)**: Fix the bad gateway error on profile exit.
*   **Story 2.2 (Reverb Fixes)**: Fix duplicate broadcasts/notifications (Critical for Real-time).
*   **Story 3.2 (Home Page Centering)**: Fix UI alignment.
*   **Story 5.3 (Anonymous Privacy)**: Fix privacy leak in emails.
*   **Story 4.3 (Time Validation Fix)**: Fix "prohibition error" on rescheduling.

## Sprint 2: Discussions & Real-time Interaction
**Goal**: Complete the high-priority adjustments to Discussions and Session management.
*   **Story 2.1 (Live Chat Completion)**: Finalize live chat features.
*   **Story 2.5 (Session Notes)**: Add ability to take notes during sessions.
*   **Story 2.3 (Notes in Chat)**: Annotate chat messages.
*   **Story 2.4 (Chat Limits)**: Limit counsellors in discussions.
*   **Story 4.1 (User Session Request)**: Allow users to propose session times.
*   **Story 4.2 (Counsellor Calendar)**: Add calendar view for counsellors.

## Sprint 3: Organizations MVP
**Goal**: Implement the core structure for Organizations.
*   **Story 1.1 (Setup)**: Create Organization models and basic CRUD.
*   **Story 1.2 (Membership)**: Implement invite/add member logic for Orgs.
*   **Story 1.3 (Client Mode)**: Allow Orgs to subscribe/pay for members.
*   **Story 1.4 (Provider Mode)**: Allow Orgs to list Counsellors.
*   **Story 8.1 (Pricing)**: Counsellor pricing display (prerequisite for Org billing logic).

## Sprint 4: User Tools & Admin
**Goal**: Enhance the individual user experience and Admin oversight.
*   **Story 7.1 (Admin Dashboard)**: Build the main Admin dashboard.
*   **Story 6.1 (Journal)**: Implement User Journal.
*   **Story 6.2 (Notification Center)**: In-app notification dropdown.
*   **Story 5.1 (ID Verification)**: Display verification badges/warnings.
*   **Story 5.2 (Institutionalisation)**: Implement recommendation flow.

## Sprint 5: Security & Polish
**Goal**: Hardening security and final polish items.
*   **Story 5.4 (2FA)**: Implement Two-Factor Authentication.
*   **Story 5.5 (Password Security)**: Password policy and checks.
*   **Story 6.3 (Notification Settings)**: Granular notification preferences.
*   **Story 3.3 (HowTo Modal UX)**: Improve "Get Started" flow.
*   **Story 8.2 (Profile Links)**: Easy sharing of profiles.

## Future / Icebox
*   **Story 8.3**: Multilingual Support.
*   **Story 8.4**: AI Emergency Assistance.
